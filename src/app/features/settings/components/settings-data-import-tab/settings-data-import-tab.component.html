Importación sumativa

La carga agrega registros; no reemplaza lo existente. Validamos duplicados en el archivo y en la base (RFC, placas, series, etc.).

El Excel solo se lee en tu navegador: no se sube a S3 ni se archiva. Se extraen las filas, se crean los registros en la base y el archivo se descarta al importar o al quitarlo.
